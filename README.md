# Need for Speed: Most Wanted - Black Edition for Xbox 360
<img width="1019" height="1436" alt="MWBE360" src="https://github.com/user-attachments/assets/c3186a18-9e93-4fd6-a77c-94533e7cced0" />

The Black Edition features additional events, bonus cars, three bonus vinyls, and a special Challenge Series event.

> **The Black Edition was never officially released for Xbox 360.**

## Black Edition Features

* Two exclusive stock bonus cars
  * BMW M3 GTR (Road)
  * Chevrolet Camaro SS
* Eight exclusive tuned bonus cars
  * Chevrolet Corvette C6 (Tuned)
  * Chevrolet Corvette C6.R (Tuned)
  * Lotus Elise (Tuned)
  * Mercedes-Benz SL 500 (Tuned)
  * Mercedes-Benz SL 65 AMG (Tuned)
  * Porsche 911 Carrera S (Tuned)
  * Porsche 911 GT2 (Tuned)
  * Toyota Supra (Tuned)
* An exclusive Challenge Series event
  * Event #70
* Three additional events
  * Circuit: City Perimeter
  * Sprint: NFS World Loop
  * Sprint: Seaside & Power Station

## Compatibility

**For RGH / JTAG modified Xbox 360 consoles and Xenia.**

These modified XEX files will not run on an unmodified retail Xbox 360.

## 640×480 Performance Versions

Optional **640×480 builds** are also included.

These reduce the rendering resolution and can provide a **better and more stable framerate** on Xbox 360.

Available as:

* 4:3 – 640×480
* 16:9 Widescreen – 640×480
